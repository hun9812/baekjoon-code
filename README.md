# 백준 풀이

Python으로 푼 알고리즘 문제를 모았습니다. 파일명은 `문제번호-풀이방식.py`입니다.

- DP: LIS, 계단 수, 포도주 시식 등
- 완전 탐색: 리모컨, 날짜 계산, 사탕 게임 등
- DFS: 테트로미노
- 분할 정복: 연속합

[연속합의 DP 풀이](1912-dp.py)와 [분할 정복 풀이](1912-divide-n-conquer.py)를 함께 남겨 두었습니다.

각 파일은 표준 입력을 받아 실행합니다.

```bash
python 11053-dp.py < input.txt
```

`input.txt`에는 해당 문제의 입력을 넣으면 됩니다.
